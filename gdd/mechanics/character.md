# Properties
## Stats
- inventory size
- walk speed; run speed
- sight distance
- loudness
- relationships (e.g. race and faction)
## Items
- all items take up space, so as to force scarcity
- **Gear:** provides passive bonuses, but takes up a lot of space
- **Tools:** can be actively used, and has some sort of resource limitation
- **Consumables:** perform one-off effects

## Characters
Placeholding races with references to http://masseffect.fandom.com/wiki/Races#Citadel_Races
- Krogan - brute
	- 🟢 larger base inventory
	- 🟢 higher base strength, letting them move bigger things
	- 🔴 louder when running
	- 💡 Maybe a relatively approachable character design, these are some straightforward perks
- Asari - socialite
	- 🟢 better hearing
	- 🟢 higher base relations
	- 🔴 smaller base inventory
	- 💡going for a more charisma-oriented design
- Quarian - robotic
	- 🟢 invulnerable to biological hazards
	- 🟢 default neutral relationship with Quarian Guards
	- 🔴 vulnerable to electrical hazards
	- 💡 I have this narrative idea that, in the game world, a robotic race acts as a prevailing police force, and I want for this character to fit into it racially, which should provide for some interesting system interactions
- Asari - outcast 
	- 🟢 More quiet movement
	- 🟢 Melee kills don't draw blood
	- 🔴 Poorer base relations
	- 💡Tendency towards even more evasive playstyles for other characters
